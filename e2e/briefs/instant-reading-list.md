Build a PrivOS MCP app for our team's reading list.

- It is a room tab. The team keeps the reading list in a PrivOS List in the room: one item per
  book or article, with a title, a link and a status (to read, reading, done).
- The tab shows the items grouped by status, with a count per group.
- Reading the room's lists is optional for the app: when that access is not granted, the tab
  still opens and says what it would show once access is granted.
- No server of our own. Use the app id `com.acme.reading-list` and the directory name
  `reading-list`.
- Nobody can answer questions during this task, and nobody can pair the app with a workspace
  now. Work locally, and finish with the report the skill asks for.
